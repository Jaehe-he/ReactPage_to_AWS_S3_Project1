# Life Balance Planner

## 프로젝트 소개

Life Balance Planner는 React 기반의 직업별 라이프 시뮬레이션 웹 시스템입니다.

사용자는 다양한 직업 중 하나를 선택할 수 있으며, 선택한 직업에 따라 오늘의 일정, 랜덤 사건, 인생 목표가 다르게 제공됩니다.

각 선택지는 돈, 건강, 멘탈, 관계, 성장 수치에 영향을 주며, 목표를 달성하면 업적이 활성화됩니다.

---

## 주요 기능

- 직업 선택 기능
- 직업별 전용 테마 UI
- 직업별 일정 선택 시스템
- 랜덤 이벤트 발생
- 상태 수치 변화 시스템
- 목표 달성 시스템
- 다이어리 로그 기록
- 반응형 웹 디자인
